# Atlas Forex Terminal

A responsive forex research-terminal interface with seven structured workflows:

- Market-priced analysis
- Technical chart analysis
- News-impact analysis
- Portfolio stress testing
- SMC strategy backtesting
- Trade review
- Daily market planning

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload `index.html`, `.nojekyll`, and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main**, folder **/(root)**, and click **Save**.
6. Wait for deployment. The site URL will be:
   `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## Local preview

Open `index.html` in a browser. No build step or dependencies are required.

## Important

The included prices and market events are illustrative. Connect licensed live-market, news, calendar, portfolio, and backtesting services before using this as a real trading terminal. This project is for research and education, not financial advice.
